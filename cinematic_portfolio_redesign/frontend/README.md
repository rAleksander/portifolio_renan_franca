# Frontend — Portfólio Cinematográfico

Aplicação web desenvolvida com React, Vite, Three.js, GSAP e Tailwind CSS.

## Funcionalidades
- **Abertura Cinematográfica:** Tela inicial independente com controle prévio de áudio opcional e botão "Iniciar experiência".
- **Explosão Cósmica (4 Fases):** Singularidade, expansão com partículas e ondas de choque, nascimento do universo e transição fluida para o portfólio.
- **Cenário 3D Persistente (Three.js):** Campo de estrelas estratificado, nebulosas volumétricas com pulso orgânico e cometas atravessando diagonalmente de cima à direita para baixo à esquerda.
- **Web Audio API:** Pipeline de áudio reativo com controle de volume, loop contínuo, e extração suave de graves via `AnalyserNode`.
- **Informações Reais:** Apresentação profissional de Renan Aleksander, projetos reais (DMT Áster ERP, RAOF Auto, Ninare, Delivery Analytics, DMT AI), stack categorizada e trajetória profissional.
- **Glassmorphism:** Cartões translúcidos com alto contraste e legibilidade impecável.

## Como Executar
```bash
npm install
npm run dev
```
Acesse `http://localhost:5173`.
