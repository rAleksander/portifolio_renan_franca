# 🌌 Frontend — Portfólio Cinematográfico

Aplicação web desenvolvida com **React 18**, **Vite 5**, **Three.js**, **GSAP 3** e **Tailwind CSS 3.4**.

---

## 🚀 Funcionalidades

- **Abertura Cinematográfica:** Tela inicial minimalista com foco tipográfico, seletor de trilha sonora prévio opcional e botão "Iniciar experiência".
- **Explosão Cósmica (4 Fases):** Singularidade, expansão de 1.800 partículas tridimensionais, nascimento do universo e transição fluida para o portfólio.
- **Cenário 3D Esférico 360° (Three.js):** 4.200 estrelas distribuídas esfericamente, garantindo ausência total de bordas vazias em qualquer resolução (incluindo ultrawide).
- **Nebulosas Volumétricas com Pulso Orgânico:** 80 nuvens cilíndricas que reagem suavemente aos graves da trilha sonora.
- **Cometas Diagonais:** Cruzam a tela espaçadamente da região superior direita para a inferior esquerda com caudas luminosas de partículas.
- **Web Audio API:** Pipeline com `AnalyserNode` para reatividade espectral suave (20 Hz a 180 Hz) e controle de volume persistente.
- **Glassmorphism de Alto Contraste:** Cartões translúcidos com bordas finas reflexivas, legibilidade garantida e tipografia moderna.
- **Projetos Reais:** DMT Áster ERP, RAOF Auto, Ninare, Delivery Analytics e DMT AI Platform.

---

## 🛠️ Instalação e Execução

```bash
# 1. Instalar dependências
npm install

# 2. Iniciar servidor de desenvolvimento (HMR)
npm run dev

# 3. Compilar bundle de produção otimizado
npm run build

# 4. Pré-visualizar build localmente
npm run preview
```

Servidor disponível por padrão em: `http://localhost:5173`
